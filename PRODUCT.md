# Product

## Platform

web

## Stack

The transfer tool is Rust. The demo is plain HTML, CSS, JavaScript and Canvas, as requested by the user; Python provides reproducible asset preparation and video recording.

## Users

Developers evaluating terminal-only file transfer and sharing an open-source project demo.

## Product Purpose

shadow-ink receives files from remote terminal output through a local tmux pane, with QR, sampled text and Base64 pipe transports, persistent recovery and SHA-256 verification.

## Capabilities and Constraints

The demo visualizes two QR configurations and Base64 transmission in left/right tmux-style panes. It supports a deterministic 45-second, 16:9 film, pause, seek and replay. Animation timing is illustrative, never a measured speed comparison. Actual protocol frames and an independently checked payload should ground the demonstration.

## Brand Commitments

The user approved English on-screen captions, no voiceover, a dark terminal and coral accents. The supplied Lenna screenshot is the local recording subject. Source code has an MIT license; a user-supplied reference image does not inherit that license.

## Evidence on Hand

The repository includes protocol documentation and native runtime validation for v0.2.1. The supplied reference image is a local screenshot. Existing measured performance claims remain scoped to their original environments.
