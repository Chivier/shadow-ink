One image. A terminal is all it takes. A file becomes independently checked shards. First, QR V12-M: 224 bytes per shard, CRC32C and Reed–Solomon recovery. Then, QR V40-L: a denser QR symbol, with 2,893 bytes per shard. Finally, Base64: the same frame protocol written as SI1 text lines through tmux pipe-pane. The receiver restores the original file and verifies its SHA-256. The visual reveal is an illustration; a separate real tmux transfer validates the file.
