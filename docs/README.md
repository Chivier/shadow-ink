# Documentation site

The GitHub Pages site is maintained in this directory as plain HTML, CSS and JavaScript. No framework, package manager or external CDN is required.

```sh
# Refresh verbatim CLI help and validate one-command option coverage.
python3 scripts/update-cli-reference.py --binary ~/.local/bin/shadow-ink

# Assemble the public docs and preserve the interactive demo under /demo/.
python3 scripts/build-site.py
python3 -m http.server 8767 --bind 127.0.0.1 --directory dist/site
```

Open `http://127.0.0.1:8767/`. Edit `index.html` for usage examples, `site.css` for presentation, and `site.js` for navigation, filtering and copy controls. The build embeds the parameter table and default help so they remain readable without JavaScript.

`cli-reference.json` and `CLI.md` are generated by `scripts/update-cli-reference.py`. The script checks that all long options in the actual `get --help` output have a friendly description; update those descriptions when the CLI changes. Regenerate with the executable matching the current source version before publishing a release.

`scripts/build-site.py` copies tracked `docs/` and `demo/` files plus the explicitly named site source files. Local-only images, frame data and rendered videos are excluded. Self-hosted demo fonts are reused in the built site and retain their bundled OFL licenses. Use a fresh output directory if the builder detects local-only demo files.

`.github/workflows/demo.yml` builds and publishes `dist/site` on changes to docs, demo or the site scripts. The root URL serves documentation; `/demo/` preserves the HTML film. Existing Markdown guides remain available in the source repository.
